# 🚀 НАЧНИТЕ ОТСЮДА

## ❓ Вопрос: "Что мне нужно сделать?"

**Ответ:** Применить 3 миграции в Supabase и загрузить CSV. Займёт 10 минут.

---

## 📋 3 Шага

### Шаг 1️⃣: Проверить что уже есть (1 минута)

Откройте **Supabase Dashboard → SQL Editor**

Скопируйте и запустите:
```sql
-- Что есть в системе?
SELECT 'Колод' as item, COUNT(*) as count FROM public.decks
UNION ALL
SELECT 'Карточек', COUNT(*) FROM public.cards
UNION ALL
SELECT 'Языков', COUNT(*) FROM public.languages; -- Должно быть ошибка или 0
```

**Результат:** Вы увидите сколько у вас:
- Колод (например: 5)
- Карточек (например: 1250)
- Языков (скорее всего ошибка - это нормально)

---

### Шаг 2️⃣: Применить 3 миграции (5 минут)

В Supabase SQL Editor:

#### 2.1 Откройте новый запрос (New query)
- Скопируйте весь текст из файла: **`supabase/migrations/0015_multilingual_system.sql`**
- Вставьте в SQL Editor
- Нажмите **Run** (Ctrl+Enter)
- ✅ Должно написать "Query executed successfully"

#### 2.2 Откройте ещё один новый запрос
- Скопируйте весь текст из файла: **`supabase/migrations/0016_multilingual_import.sql`**
- Вставьте в SQL Editor
- Нажмите **Run**
- ✅ Должно написать "Query executed successfully"

#### 2.3 Если нужно - применить 0014 (обычно уже есть)
- Скопируйте весь текст из файла: **`supabase/migrations/0014_admin_manage_user_decks.sql`**
- Вставьте в SQL Editor
- Нажмите **Run**
- ✅ Должно написать "Query executed successfully" или ошибка про "already exists" - обе нормально

**Проверка что все прошло:**

Запустите:
```sql
-- Проверка 1: Есть ли языки?
SELECT COUNT(*) as languages FROM public.languages;
-- Ответ должен быть: 12

-- Проверка 2: Есть ли функция импорта?
SELECT EXISTS (SELECT 1 FROM pg_proc WHERE proname = 'import_multilingual_cards');
-- Ответ должен быть: true (или t)
```

**Если оба ✅ - идём на Шаг 3!**

---

### Шаг 3️⃣: Загрузить данные (2 минуты)

В приложении:

1. Откройте приложение (http://localhost:5173 или ваш сервер)
2. Войдите как **Суперадмин**
3. Перейдите в **Admin Panel** (меню сверху)
4. Нажмите на вкладку **"Vocabulary"** (новая! между Users и Content)
5. Выберите из списка **Student** (например, "Vasiliy" или любого)
6. Выберите или создайте **Deck** для этого студента
7. Нажмите **"Add words"** (кнопка справа)
8. В диалоге нажмите на **"Paste"** или **"File"**
9. Если File: загрузите `examples_multilingual_ukrainian.csv`
   Если Paste: скопируйте содержимое этого файла
10. Нажмите **"Upload"**
11. ✅ Готово! Должно написать "Загружено карточек: 18"

## ❓ Что Если Не Работает?

### "Не вижу вкладку Vocabulary в Admin Panel"
- Перезагрузите страницу браузера (F5)
- Очистите кэш (Ctrl+Shift+Delete)
- Выйдите и войдите заново

### "SQL запрос выдаёт ошибку"
- Дайте мне текст ошибки
- Скорее всего нужно заново запустить миграцию
- Или использовать другой браузер / режим инкогнито

### "Не получается скопировать текст миграции"
- Откройте файл в VS Code
- Ctrl+A (выделить всё)
- Ctrl+C (скопировать)
- Вставьте в SQL Editor
