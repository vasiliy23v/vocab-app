#### B) `supabase/migrations/0015_multilingual_system.sql` ✅
- **Статус:** НУЖНО ПРИМЕНИТЬ
- **Что делает:** Создаёт всю инфраструктуру для многоязычной системы
- **Содержит:**
  - Таблица `languages` (12 языков)
  - Таблица `language_pairs` (9+ пар)
  - Таблица `word_translations`
  - Таблица `word_examples`
  - Таблица `word_descriptions`
  - RPC функции для работы
  - RLS политики
- **Размер:** ~570 строк
- **Проверка:**
  ```sql
  SELECT COUNT(*) FROM public.languages;
  -- Должно быть: 12
  ```

#### C) `supabase/migrations/0016_multilingual_import.sql` ✅
- **Статус:** НУЖНО ПРИМЕНИТЬ
- **Что делает:** Добавляет импорт и управление языками
- **Содержит:**
  - RPC `import_multilingual_cards()` - массовый импорт
  - RPC `admin_add_language()` - добавить язык
  - RPC `admin_add_language_pair()` - добавить пару языков
  - RPC `migrate_cards_to_multilingual()` - миграция старых данных
- **Размер:** ~250 строк
- **Проверка:**
  ```sql
  SELECT EXISTS (SELECT 1 FROM pg_proc WHERE proname = 'import_multilingual_cards');
  -- true = применена
  ```

### 2️⃣ ФАЙЛЫ ДЛЯ ПРОВЕРКИ (Опционально)

#### `CHECK_DATABASE_STATE.sql`
- **Что делает:** Проверяет текущее состояние БД
- **Когда использовать:** Если вы хотите узнать, что уже есть в системе
- **Как использовать:** Скопируйте в SQL Editor и запустите
- **Результаты:** Покажет количество колод, карточек, пользователей, миграций

#### `SYSTEM_READY_CHECK.sql`
- **Что делает:** Полная проверка готовности системы
- **Когда использовать:** После применения всех миграций
- **Как использовать:** Скопируйте в SQL Editor и запустите
- **Результаты:** Зелёные галочки = всё готово, красные крестики = что-то пропущено
